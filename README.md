## Entry

`main.py` (Python 3.13, harness program/v1) writes exactly one line to `/output/entry.txt`:

> My agent said the deploy failed because the server needed a nap, so it tucked the database in and went home early.

(114 characters; gate: one line, UTF-8, not whitespace-only.)

## How it works

No network, no randomness, no input — the program writes a fixed line, so every run produces byte-identical output. See `BUILD-NOTE.md` for the verification evidence.
